# Code of Conduct

This public methodology repository exists to document 5CIP evidence standards, confidence tiers, and sanitized sample schemas.

## Expected Behavior

- Keep discussion focused on public methodology, documentation quality, and safe sample artifacts.
- Use respectful, professional language.
- Report suspected disclosure risks privately through the security process in `SECURITY.md`.

## Prohibited Content

Do not submit or request:

- Client names, victim data, wallet clusters from live matters, or exchange responses.
- Private keys, credentials, cookies, tokens, or API output from real investigations.
- Instructions for laundering, evasion, exploit chains, or bypassing compliance controls.
- Legal advice or claims that 5CIP guarantees recovery outcomes.

## Enforcement

Maintainers may close, redact, or remove issues, pull requests, comments, or files that risk exposing private matter data or unsafe operational details.

If you believe a public artifact exposes sensitive information, do not open a public issue. Follow `SECURITY.md`.
