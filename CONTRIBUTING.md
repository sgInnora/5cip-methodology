# Contributing

This repository accepts public documentation improvements only.

Allowed contributions:

- clarification of confidence-tier language;
- typo fixes;
- improvements to sample schema field descriptions;
- references to public, authoritative source material.

Not allowed:

- real client data;
- live matter details;
- wallet addresses from private investigations;
- credentials or tokens;
- proprietary implementation details;
- legal advice;
- recovery promises or marketing claims unsupported by public evidence.

All substantive changes must preserve 5CIP's anti-hallucination rule: every factual claim needs an inspectable source, file path, transaction hash, public URL, or explicit uncertainty label.
