# Security Policy

## Reporting Security Issues

Report security issues to:

- security@5cip.com

Do not open public issues for vulnerabilities, client data, credential exposure, or active investigations.

## Sensitive Data Policy

This public repository must never contain:

- client names or matter identifiers;
- live wallet addresses from private matters;
- private API responses;
- credentials, tokens, cookies, keys, or `.env` files;
- proprietary trace-engine code;
- exploit payloads or laundering instructions.

Only sanitized public methodology documents and synthetic examples are allowed.

## Scope

The production platform runs at:

- https://5cip.com/

This repository is a public documentation and schema surface only. It is not the production application.
